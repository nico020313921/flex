TRABAJO PRACTICO FlexSpace
Se avanzó con las clases principales y con una parte importante de la lógica de negocio. También se comenzó a implementar el acceso a la base de datos, especialmente para las operaciones relacionadas con los clientes.

Sin embargo, el proyecto quedó incompleto. Las clases PuestoDatos y ReservaDatos todavía no tienen implementados sus métodos, aunque la lógica de negocio ya los utiliza. Además, la clase Program de la capa de interfaz de usuario todavía está vacía, por lo que falta desarrollar la interacción con el usuario y conectar las distintas funcionalidades para utilizar el sistema de forma completa.

También quedaron pendientes completar y verificar la base de datos y su publicación en GitHub, ya que durante la entrega se presentaron problemas al subirla de forma completa.
